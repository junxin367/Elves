# 工作区文件查看规划：本机与远程

2026-11-28。**用户已确认按下列顺序实施；本机和远程文件面板均不提供“下载原文件”入口。** 下表保留设计目标，不把源码接入或本机自动化测试等同于公网、安装版或 Android 真机验收。

## 用户打开的到底是哪份文件

| 入口 | 计划中的行为 |
| --- | --- |
| Elves Windows 本机客户端，包括其独立文件窗口 | 当前会话的项目原件就在本机。通过现有本机 Harness 的回环入口（默认 `127.0.0.1:45223`）校验并读取该原件，在客户端内显示或播放，不经过远程监听、公网隧道或云服务，不先复制一份文件。关闭远程、断开外网、撤销远程设备，都不应打断已经打开的本机视频。 |
| 远程 PC 网页、手机网页、PWA、Android | 读取的仍是运行 Harness 的电脑上的文件；显示、解码和播放发生在**访问的这台设备**。只有已授权的查看请求可以跨网络，按查看动作传需要的数据。在宿主机上弹出系统播放器或浏览器，不算远程播放成功。即使在同一台电脑上用普通浏览器访问远程入口，仍适用远程规则。 |

两端都通过已有会话 `threadId` 或新建页所选 `projectId` 确定项目，侧边会话引用沿用其来源身份。文件树以实际项目为界；已有正文引用可访问的所属引擎目录不扩展到文件树。Windows 磁盘文件和已核验的所属 WSL 工作区分别读原件；不能确认发行版、文件身份或最终路径时说明原因，不猜另一个目录，也不让 WebView 传任意 `file://` 地址。PC 保留右侧文件标签，手机保留整页返回，均不打断聊天或启动模型。现有正文“浏览器打开”和本机“打开方式”的语义不变。

## 文件类型与查看动作

| 文件 | 本机客户端 | 远程会话 | 首版不做什么 |
| --- | --- | --- | --- |
| **文本、代码、JSON、Markdown、日志**（已确认） | 4 MiB 以内维持原体验；超过仍能查看，正文每次最多读 256 KiB，只绘制可见区域。一般文件从头看，大 `.log` 从末尾看，可双向翻、跳首尾。 | 同一行为，每次只传所读片段；超长单行不能触发整文件读取。界面显示片段范围，不把局部结果当全文。 | 不把 4 MiB 变成禁止打开的上限、不自动渲染大 Markdown 全文、不新增全局大小设置。编码与字符边界见[已确认方案原文](validation/workspace-large-file-preview-2026-11-28.md)。 |
| **视频、音频** | 在“文件”里点开先显示名称、大小和播放按钮；点播放才从本机原件取数据，拖进度条直接定位。不因文件为 20 MiB、200 MiB 或 2 GiB 拒绝；不必打开外部播放器。 | 先给文件信息与可用封面，不自动传音视频正文。点播放后，播放器从当前授权线路分段取原件；拖到后半段直接取相应位置，不先下载前半段。 | 首批用 MP4（H.264/AAC）和 MP3 验收；WebM、M4A 等以设备实测解码能力为准。首版不自动转码或生成多档清晰度；编码不支持、文件损坏与线路中断分别提示，原因无法判定时不乱报。 |
| **位图、动图、SVG** | 点开查看本地原图；按像素尺寸和解码内存决定是否生成缩略图或允许原尺寸，不能仅凭压缩文件字节数拒绝。GIF、APNG、动画 WebP 如只展示静态封面要明确标识。 | 默认只传适合当前预览的图；用户点“查看原图”才取原始图像，仍受像素和解码预算保护。缩略图失败不自动改传大原图。 | 不因扩展名为 `.svg` 就当可信图片；沿用 SVG 安全校验，不允许脚本或外部资源进入工作区页面。 |
| **PDF** | 小文件保留现有文本预览；建议下一阶段增加可看版式的分页阅读，尤其是没有文本层的扫描件。打开先显示所选页，不要求用户先导出图片。 | 先取页信息、所选页及解析目录/索引所需的片段；若阅读器或文件不能做到有界读取，则改用已验证的分页派生图，或明确提示该文件暂不可预览。不静默下载整本。 | 不承诺每份 PDF 都只读一段就能出首页；加密、损坏、无文本层分开说明，不把扫描件报为空文件，不默认做 OCR。 |
| **表格、文档、演示文稿** | `.xlsx/.ods` 按工作表和行窗、`.docx/.odt` 按段落、`.pptx` 按幻灯片查看；保留小文件已支持的格式、样式和工作表切换。CSV/TSV 超出结构化解析预算时仍可按已确认的文本方案阅读。 | 在 Harness 端做有界解析，传当前工作表行窗、段落或幻灯片，不为了首屏把整个 Office 原件传给手机；清楚标出返回范围及截断原因。 | `.xls/.doc/.ppt` 首版保留现有格式说明；不执行宏、公式或外部链接，不把结构化预览说成 Office 原样排版。ZIP 解压、XML、单元格、总文本量仍分别设限。 |
| **压缩包、专业格式和未知二进制** | ZIP 只读列目录和条目大小；其他如 7z、CAD、PSD、数据库、可执行文件显示文件名、大小和不支持原因。已有明确外部操作不变，不在文件树恢复通用 `Default app`。 | ZIP 只传目录页，不传整包；远程不启动宿主机软件。 | 不解压到磁盘、不运行文件、不向第三方上传转换；失败也不提供原文件下载。 |

HTML、XML 和脚本在“查看源码”里仍是文本，不在已授权工作区页面里执行。Git 变更、模型读文件和聊天附件上传不在本规划内；“能查看 200 MiB 文件”不表示能全文做差异比较或上传给模型。

## 先把本机做简单，再把远程做可靠

**本机：** 复用现有 Harness 本机授权和同源回环入口，不新增监听端口，不直接开放整个目录。文件页先取元数据，再用同一份已校验的文件句柄按需读取。媒体可复用[会话播放器](../assets/harness/attachments.js)和[已有 Range 读流](../crates/elves-harness/src/video.rs)的播放、拖动、关闭逻辑；现有视频登记来源是会话正文，不是文件树授权。应抽取接收已校验句柄的读流部分，不能直接把网页传来的路径塞入旧登记表。已有本机外部打开只作为用户选择，不是本机文件预览的必经步骤。

**两端共用的读取约定：** 先返回文件名称、大小、版本及当前可用的查看方式；扩展名是线索，需要识别格式时先取不超过 4 KiB 的文件头，再交给对应格式的有界探测或解析。目录只列条目，不为整棵树逐个取样。版本跟随已打开的文件身份与变更信息，不为生成版本号或封面先算整文件哈希；文件被同名替换、无法确认版本连续性时，废弃旧句柄和片段。图片/PDF/Office 即使在本地，也保留解码和解析的内存、像素、页数或解压预算，这与公网限流无关。Office 阶段不能只调高 4 MiB 常量：先核实容器目录，再只解压当前视图所需条目；现有解析器的解压总量 32 MiB、单项 16 MiB 等保护在验证新读取器前不调高。

**远程：** 在上述读取能力上增加以下约束，不将公网限流套在本机读盘上：

1. **谁可以读哪一项。** 打开时绑定当前监听入口、设备授权、原会话或所选项目、文件与版本；媒体地址用不含磁盘路径的资源标识，不在 URL 里放密钥或设备凭据。每次取元数据、封面、分段和重连都复核这些条件，资源标识本身不能授权。只读设备能看已获权的文件，但不能写、执行或据此获得导出权限。撤销设备、换密钥或关闭远程时，拒绝新请求并取消正在发送的旧流；无法收回已传到设备的字节。其他设备与本机播放不受单台设备撤销影响。
2. **点什么，传什么。** 文件列表不预载原件或批量生成视频封面；媒体打开可取封面，点“播放”才设置正文源。文本用 256 KiB 分块；媒体用 HTTP 单段字节范围，不把文本块大小当成视频上限。`HEAD` 不带正文；合法 `Range` 返回 `206` 和准确的 `Content-Range`，不可满足的范围返回 `416`；没有 `Range` 的兼容请求按需流式返回 `200`，客户端中止后停止读盘，不在内存里拼全文件。参考 [HTTP 范围请求](https://www.rfc-editor.org/rfc/rfc9110.html#section-14)。
3. **拖动、断线、换文件。** 拖动时取消上一段；关闭查看器即取消读取并释放句柄。切换会话或隐藏媒体标签，暂停并只保留原位置；返回后由用户续播。网络断开保留时间点，恢复时先核对同一设备、来源和文件版本，只续同一文件；文件替换或截短则提示重新打开，不将旧片段接到新内容上。授权失效时清空查看器，不展示旧封面或借别的会话重试。
4. **控制开销。** 读取固定大小的磁盘缓冲，客户端消费慢就停止向前读取；旧的播放、封面和解析任务可取消。首版提议每台远程设备同时最多 **2 个媒体响应**，快速拖动优先新位置；封面、图片解码与文档解析复用有界工作队列，聊天发送/审批不排在媒体队列后。这是待实测的并发预算，不是文件大小或格式限制。资源响应不写入公开资源包、Service Worker 或持久文件缓存；线路不可用时不把授权转给任意来源，也不退回调用宿主机浏览器。

**旧版兼容：** 新客户端只在服务声明支持该文件能力时使用新入口；只有旧读取接口时保留现有小文件预览并提示大文件需更新 Harness。旧客户端仍可用原接口；不改变 `/api/workspace/view/...` 和 `/api/workspace/open-browser` 的用途，不通过扩大它们的上限交付媒体能力。

## 交付顺序与验收

下列是拟实施顺序和验收条件，**不是已通过的测试**。后一步不阻塞前一步单独交付。

| 顺序 | 做什么 | 怎样算完成 |
| --- | --- | --- |
| 1. 已接受的文本 | 项目文件元数据、分块文本、日志从末尾读。在本机和远程都接入。 | 20 MiB 源码可读到末段，200 MiB 日志首屏来自末尾；200 MiB 单行 JSON 不先读完整行。UTF-8 和带 BOM 的 UTF-16 跨块不乱码；用读取字节数验证，不只看首屏截图。 |
| 2. 本机音视频 | 将文件树、文件标签、独立文件窗口接到本机原件，先验播放器与安全读流。 | 关闭远程、断开外网，分别对 20 MiB、200 MiB、2 GiB 本地样本点播放并拖到 90%；实际在 Elves 播放、无公网请求、未复制整文件。非支持编码有错误；Windows 和已支持的所属 WSL 路径分别验证。 |
| 3. 远程音视频 | 复用同一播放器，补足授权、流量、线路恢复和并发控制。 | 用远程 PC、手机浏览器/PWA、Android 实测，在局域网及实际可用的公网线路核对：点播放前视频正文为 0 字节；快速拖动不顺序下载前 90%；弱网/断线续播能回原时间点。播放途中撤销一台设备，观察旧流终止、新片段被拒，本机仍可播放；媒体满载时聊天仍可发送。各端、各线路分别记录，不互相代验。 |
| 4. 图片、PDF 与 Office | 先补受控的大图预览，再做 PDF 原页和扫描件，最后为 Office 增加分表、分段、分幻灯片读取。 | 小字节超大像素图片不能耗尽内存；动图和静态封面不混淆；普通扫描 PDF 样本要在 Windows、远程浏览器与 Android 看到所选页，超预算样本单独测拒绝。选一个在解压预算内的 20 MiB 工作簿验证只展示所选表与行，再用超预算样本验证明确拒绝；同时核对首屏传输量、解析峰值、取消后停止工作。 |
| 5. 压缩包及其他文件 | 展示元信息与有界 ZIP 目录，不提供原件导出。 | 普通 ZIP 可分页面查看，目录过大、加密或不支持时说明原因；未知格式仍能看到大小和类型。没有通用下载按钮、归档条目提取或宿主机启动动作。 |

## 已确认的下载边界

**不提供“下载原文件”按钮、通用导出接口、设置开关或失败后自动下载。** 播放或查看原图仍需将已授权的可解码字节送入访问设备；这是预览，不是防复制或撤回已发送字节的承诺。

## 实施与验证记录

本次在当前工作区按序接入了 `workspaceFilePreview`、项目级只读预览和仅供已授权音视频/位图使用的流接口。文件树、现有会话、所选新建项目与本机独立预览沿用原身份。新网页连旧 Harness 仍使用旧路径。没有新增下载按钮、通用下载接口、外部转换服务、安装或发布步骤。

| 项目 | 实际验证与限制 |
| --- | --- |
| 远程访问边界 | 使用临时项目、只读设备和随机回环端口启动真实远程 HTTP 路由。区分了无来源/错误来源与同源但无授权；校验了路径越界、混合身份、伪造宿主目录、跨设备/本机入口借用资源标识、范围越界、并发和中止。资源 URL 不携带设备密钥。 |
| 大文本、文档与图片 | 使用 20 MiB 单行文本、200 MiB 日志、跨块 UTF-8／UTF-16、超过 20 MiB 且在解压预算内的双工作表工作簿、分页 ZIP 和 DOCX 测试。Windows PDF 组件对无文字层样本返回 PNG 页图并校验了实际像素，不只是检查响应类型。Office 保留 32 MiB 总解压及 16 MiB 单项预算；PDF 原页当前采用最多 32 MiB 输入、最长边 1400 像素的宿主机派生图，不把 PDF 原件送到浏览设备。 |
| 实际媒体解码和跳播 | 独立无头 Chrome 访问本机回环和远程入口；以 20 MiB、200 MiB、2 GiB 的**可播放合成 MP4**逐个点播放、跳到时长 90%，在两个入口均观察到靠近文件末尾的 `Range`。样本使用合法填充段将媒体数据置于文件后部，验证读盘/传输定位，不能据此推断持续高码率吞吐。阻断媒体请求再恢复后，手动重试可继续播放。 |
| 页面交互 | 在远程 1190px、本机回环 1060px、远程 390px 触屏模拟视口，验证 MP4／MP3 的播放、关闭、播放前无媒体正文请求、文本跳末尾、日志尾段、PDF 翻页及 ZIP 条目。三组均未发现页面 JS 错误。独立浏览器用的是本次源码和隔离设备授权，不是对用户桌面已安装的二进制进行验收。 |
| 凭据与来源文件变化 | 已验证设备到期、换密钥、撤销单台设备、文件同名替换与流中截短。真实 HTTP 响应已收到首块后撤权，旧响应不能正常收完整个文件，后续请求被拒；另一台仍获授权的设备可继续请求，关闭远程后本机仍可取末尾片段。 |
| Windows 与 WSL | 工作区后端回归 50 项通过；显式独立运行真实 `codex-elves-claude-test` WSL 临时项目用例，5 MiB 文本可通过已授权请求读取首个 256 KiB，不要求项目必须有 Git 仓库。双通道授权回归另行通过。没有连接正式会话或要求模型处理测试文件。 |
| 尚未覆盖 | Android 真机、已安装 PWA、Windows 原生窗口内 WebView2、真实局域网设备和公网隧道（zrok／FRP／ngrok）未在本轮代验；没有持久弱网带宽、峰值内存或长时高码率指标。解析任务在有界工作槽内运行，已经进入系统 PDF/图像解码的同步工作不保证瞬间终止；授权失效后不能向客户端返回结果。 |

后续设备验证应使用隔离测试项目，不为验收而打开用户正式远程入口；按[工作区工具的内容查看规则](product-standards/sessions/workspace-tools-and-side-sessions.md#内容查看)分别记录实际使用的客户端、线路和编码。
