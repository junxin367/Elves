# 后台任务只读展示验收

## 本次行为

- 会话菜单在子智能体前显示后台任务；每行只有图标、原生名称和执行时间，无停止、重试或详情操作。
- 无任务时不创建整个分组；任务清零时恢复菜单右上方块。
- 有任务时右上角使用命令图标和两秒柔和呼吸；左下角侧边未读独立显示。减少动画模式保留静态提示。
- 输入框上方原有后台任务横幅移除。断线、会话或授权切换清除旧运行提示，重连必须等新快照；迟到的 HTTP 读取不能覆盖更新的结束事件。

## 数据与时间

目前接入共享 Claude 原生任务事件。显示列表排除明确前台任务及 ambient 任务，原有原生任务保活保护单独保留。任务名称按文本展示，不能作为 HTML 执行。

用时依据原生开始时间、宿主首次收到开始事件的时间或原生进度时长。宿主保存首次观察时间，并在任务稍后转入后台及 Harness 重连时补发，不能从打开页面或重连重新计时。缺少证据显示 `—`。网页沿用菜单计时器，只更新文字，不因时间变化重建菜单或额外请求。服务端比较同一快照前后视图时使用相同时间基准，避免仅因用时变化重发历史。

旧 Claude 宿主仅有数量摘要时只展示已有类型和数量。当前 AGY、Codex 未接入已核验的当前后台任务列表，本次没有为它们推断任务或扩展执行接口。

## 验证边界

浏览器使用隔离数据驱动实际组件，没有请求真实 API 或执行任务操作。上述验证没有启动新的真实模型会话，也未停止现有任务、安装客户端、切换服务、推送或生成安装包。
