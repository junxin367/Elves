# Token 统计文字明细验收

## 最终行为

- 移除表格、表头和数量/费用对齐列，显示“名称 数量 · 费用”，末尾合计略加粗；模型在顶部，关键指标在底部分组。
- 详情最大宽度 308px，内部左右各 16px，视口两侧至少留 8px；指标每行最多两项，空间不足时自动换行。
- 标题、Token 数量、费用及关键指标统一继承 `--menu-description-font-size`。沿用公共 `applyAppearance()` 的 `Math.round(界面字号 × 0.7857)`，不再逐层缩放；界面 14、18、20px 对应统一的 11、14、16px。
- 未知费用仍显示 `—`，极小非零费用显示 `<$0.0001`，真实零值保留；不显示单价、公式或介绍。
- 悬停、点击固定、键盘关闭、文本选择复制及原位数据更新沿用共享交互；新轮次尚无统计时关闭旧详情。

主规则维护于[会话 Token 统计 hover](../product-standards/core/product-behavior.md#会话-token-统计-hover)，实现和样式处保留用户要求注释。
