# 管理页面内容宽度验收

日期：2026-11-17。范围：代理设置、会话管理、远程会话。

三个页面共用 `management-page-width` 容器。标题、刷新入口、提示信息和卡片的内容宽度上限为 1000px，在主导航右侧可用区域内水平居中。桌面滚动区对称预留滚动条位置；760px 以下保留原有手机内边距，按可用宽度收缩。

## 验证

使用当前构建的前端资源、隔离 Harness 和隔离 Chrome 浏览器，从实际主导航逐项进入三个页面。

| 窗口尺寸 | 结果 |
| --- | --- |
| 1920 × 720、1440 × 900 | 三个页面标题及内容宽度均为 1000px，中线与管理区域中线一致 |
| 1100 × 800、1000 × 800 | 三个页面按可用宽度收缩，标题和内容保持居中 |
| 760 × 900、390 × 844 | 三个页面沿用手机留白，无页面或内容区域横向溢出 |

18 组布局断言全部通过，并检查了三个页面的宽屏画面和窄屏控件换行。未保存配置、发送消息、删除会话或启用远程服务。

`npm --prefix apps/elves-management run check`、`npm --prefix apps/elves-management run vite:build` 和 `git diff --check` 通过。已更新入库的管理页面资源及资源修订号；未构建安装包，未替换正在使用的客户端或正式服务。
