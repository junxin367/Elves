# 定时发送编辑验收

适用于会话输入框下方的定时发送列表。用户已确认原需求中的“标记”为“编辑”，菜单仅提供“编辑”“删除”。验收完成时尚未提交、推送、打包、安装或切换正式服务，保留工作区此前的 AGY 与 Token 改动；后续提交状态以 Git 记录为准。验收时源码资源版本为 `2026112708`。

## 完成效果

- 删除图标替换为与消息队列一致的“更多”入口，复用公共菜单和键盘操作。
- 编辑弹窗回显正文与发送时间，保存时原位更新同一任务；附件、Skill、模型设置及当前输入框草稿保留。取消不写入，未保存关闭时确认；保存失败保留内容，结果未知时禁止重复提交并说明关闭不会撤销已提交的修改。
- 后台按任务版本拒绝跨端覆盖，编辑与到期认领共用状态锁。发送中、重启后仍在核对回执及结果未知的任务不能编辑；明确失败的任务可编辑并改期，使用新的发送身份，避免复用旧失败回执。
- 修改也受存档容量限制；旧服务没有编辑能力时禁用编辑并显示原因，原删除能力保留。

规则维护于[会话定时发送主规范](../product-standards/core/product-behavior.md#会话定时发送)，实现处保留需求注释。
