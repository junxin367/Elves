# 侧边会话名称与关闭同步验收

日期：2026-11-27。

## 范围与原因

修复 PC 网页与 Elves Windows 客户端共用工作区中，侧边会话命名后标签仍显示旧名称、会话确认关闭后仍残留标签的问题。行为约定见[子会话的侧边标签](../product-standards/core/product-behavior.md#子会话的侧边标签)。

检查源码并通过反例回归确认：

- 标签文字和提示只在创建时取名称，后续 iframe 通知仅更新运行与未读；名称事件和关联列表也没有接到标签更新。
- 侧边页面通知的去重签名不包含名称和关闭状态，仅改名或关闭时无法独立触发同步。
- 持久侧边关闭回执已有标签清理，临时侧边的终态处理只清目录与正文缓存，漏掉标签；嵌入页还会沿用整页返回逻辑，在原标签内导航到主会话。
- 补齐更新后，重复的 iframe 状态和菜单缓存仍会携带旧名称，可能覆盖另一来源已经确认的新名称。新增反例确认后，按来源记录最近观察到的标题，仅应用该来源实际发生变化的名称。

后端已有名称事件、关联列表及明确的关闭通知。本次只修复前端消费和页面生命周期，不新增原生调用、不接入 Codex App 桥接。

## 实现

- 原位更新标签文字、悬停提示、读屏说明、关闭按钮说明和 iframe 的标题，不重建 iframe。
- 名称事件、关联列表与侧边页面状态三条路径均可更新保留标签；只变化运行或未读的重复标题不回退名称。
- 确认关闭按会话 ID 清理当前授权下的对应标签；迟到通知不依赖当前主会话，后台关闭不切换当前页面。
- 嵌入页收到确认关闭后上报外层并等待卸载，不在 iframe 内打开主会话。
- 保留来源窗口、同源、会话 ID、字段类型及授权检查。过期、未知回执和不完整的持久侧边列表不视为确认关闭；持久侧边原有历史、队列与执行行为不变。
- 资源修订号由 `2026112716` 递增为 `2026112717`。
