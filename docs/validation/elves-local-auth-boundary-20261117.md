# 本机免密与远程管理权限验收

日期：2026-11-17。

## 变更

- 独立客户端忽略历史远程登录标记；401 通过受限原生命令恢复本机 Cookie，保留草稿和待确认回执，不索取远程密码、不重发写操作。多个窗口串行恢复，并复用仍有效的本机凭据。
- 网页、PWA、Android 仅显示会话入口及普通设置。代理配置、请求日志、会话管理、远程访问配置及全部 `/api/management/` 接口仅供真实本机身份使用。
- 远程管理页面及接口在请求体解析和缓存复验前返回 403。有效远程设备 Cookie、原生客户端标记或其他客户端类型均不提升权限。
- 本机及远程使用不同资源清单；远程清单和 Android 内置包排除管理页面，PWA 和 Android 在读取旧管理缓存前拒绝访问。
- Windows 管理资源缓存仅为原生绑定的同一回环 Origin 的管理资源附带 Cookie；该缓存的下载请求不向公开资源、API、其他端口及公网地址附带凭据，凭据不写入磁盘缓存。
- Harness 私有协议升级至 12，避免新客户端继续复用仍向远程开放管理的旧后台。

## 验证

- 全量 Node 检查 781 项通过；随后新增的 PWA 旧管理缓存拒绝用例定向通过。
- 本机授权与真实 HTTP 隔离测试 8 项通过，覆盖无远程密码启动、本机与远程 Cookie 隔离、一次性证明、回执恢复及远程管理接口拒绝。
- 管理相关测试 4 项通过，包括直接分发拒绝远程身份、私有管理令牌与 Origin 限制；资源清单真实 HTTP 检查通过。
- Windows 资源缓存测试 8 项通过，覆盖实际管理资源下载携带授权、公开请求不携带授权、同源绑定、多窗口共享与原有摘要和原子更新行为。
- 前端类型和资源检查、Rust 编译及格式检查通过。

## 真实进程验证

使用独立客户端、Harness、Codex Home 和 WebView 数据目录；关闭远程功能，未配置远程访问密钥，也未发送模型任务。

调试客户端成功建立本机工作区 WebSocket，状态为 101。通过一次性证明替换本机 Cookie 后，客户端自动取得新授权，约 12.2 秒后重新建立工作区连接；设备 ID 保持不变。验证脚本未取得或复用客户端内存中的原生凭据。

桌面工具的 native pipe 不可用，无法完成实际窗口截图和点击验收；上述真实进程结果以服务端连接记录及设备身份变化为依据。
