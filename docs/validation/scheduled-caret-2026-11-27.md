# 定时发送标签与光标位置验收

日期：2026-11-27。

## 行为

按[会话定时发送规范](../product-standards/core/product-behavior.md#会话定时发送)，定时标签保持在内容最前方：

- 空内容确认时间后，光标位于标签后，可直接输入正文。
- 已有内容确认时间后，正文光标或选区保持原位置，包括多行文本和 Skill 前后边界。
- 点击已有定时标签修改时间同样保留编辑位置。
- 取消、会话或授权变化、旧输入框失效时不应用旧选区；编辑已创建任务的独立弹窗不读取正文选区。

## 检查与修改

定时标签原本已通过 `writePromptContent` 插在正文前方。目标功能会保存 `promptSelection` 并用 `setPromptSelection` 恢复；定时选择只重新调用 `focus`，且原生 dialog 的关闭事件还会再次恢复触发控件焦点，没有恢复正文位置。

在打开时间弹窗前保存正文选区，确认后先渲染标签、记录草稿，等原生关闭事件完成默认焦点恢复后，再复用目标的正文与 Skill 边界换算还原选区。恢复同时核对原会话范围及输入框身份。

浏览器另外复现：点击已有标签会先将正文光标移到标签前。标签主指针按下时阻止该默认选区变化，仍由原有 click 入口打开时间选择，不改变其他指针操作。
