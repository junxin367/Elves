# 编辑框图片格式与附件拖放粘贴验证

日期：2026-11-17。代码已接入新增格式和附件输入流程；本次没有更新正式远程入口、安装客户端或构建 Android APK。

## 实现

- 图片输入新增 BMP、AVIF、静态 SVG、ICO/CUR，兼容 APNG、JFIF、JPE 及 JPEG MIME 别名。新增格式先实际解码再转换为 PNG，保存实际大小、格式和原名称；原有 PNG、JPEG、GIF、WebP 仍保留原内容。
- 图片输入与转换结果均执行单张 5 MiB、合计 12 MiB、最多 8 张及既有尺寸限制；转换失败和超限不清除已有附件。SVG 脚本、动态内容及外部文件和网络引用在进入解码前拒绝，原文不插入页面。
- 编辑框接收图片、文件、目录混合拖入和粘贴。拖放事件内捕获浏览器提供的对象，目录持续分页读取到结束，保留层级、空目录及文件字节；最多 16 个文件或目录根项、512 个清单项、32 层及 12 MiB 文件内容。
- 浏览器可以发送它在本次操作中实际提供的文件与目录内容，发送资格以服务能力为准；原生文件选择器菜单继续仅在支持对应桥的 Windows 客户端显示。
- Windows CF_HDROP 混合项中的顶层图片进入图片通道，文件夹内部内容保持文件夹结构；兼容没有 DOM paste 的目录粘贴且只添加一次。普通文字路径不触发文件读取。
- 浏览器没有提供目录对象时，不扫描或猜测本机路径。目录粘贴的可用范围由实际浏览器接口决定；Windows 独立客户端保留系统剪贴板补读。
- 切换会话、项目或授权后忽略迟到结果；普通文件和目录遍历最多读取 30 秒。失效、超限、不可读取或越界时说明原因，混合批次失败不插入部分内容。
- 保留 Tauri 的 HTML 拖放配置、现有 40×40 预览、草稿及可靠发送回执。Android 有序图片选择器继续使用其识别的单一 `image/*`。

Chrome 验证使用独立 HeadlessChrome 157 会话和本机生成的 PNG、JPEG、JFIF、WebP、GIF、BMP、AVIF、SVG、ICO、CUR、APNG 图片，逐一验证添加、输出格式、实际大小、再次解码和预览。另在浏览器中构造 DataTransfer、ClipboardEvent 验证混合图片/文件流程、损坏图片保留原附件及 SVG 外部引用拦截。没有把构造事件报告为系统剪贴板或系统目录拖放的实机操作。

目录专项使用真实 Blob 内容和目录入口/handle 夹具，覆盖超过 100 项的多页目录、空目录、32 层/512 项/大小上限、权限拒绝、版本失效及不静默截断。原生剪贴板桥返回值夹具验证图片分类和目录内容保留；服务端沿用相同附件结构校验，不接收客户端真实路径。

临时验证服务、图片、页面和浏览器记录均已清理，未纳入提交。没有新增独立测试文件，回归用例补充至既有测试入口。
