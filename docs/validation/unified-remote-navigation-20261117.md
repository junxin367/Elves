# 统一远程主导航与单客户端安装验收

日期：2026-11-17。范围：远程主导航、共享管理页面、管理 API、本机后台、Windows 安装包。桌面版本保持 0.8.0，网页资源版本为 2026111703。

## 实现范围

- 主导航按会话、代理设置、会话管理、远程会话固定排序，底部为设置。
- 代理设置合并供应商配置和本地代理；会话管理保留浏览、筛选和单个/批量删除，移除历史修复与上下文压缩配置；远程服务、公网入口、密钥和设备管理迁入远程会话页。
- 删除管理器窗口、任务看板窗口和独立应用入口。原共享命令作为后台库编入客户端，不依赖 Codex App。
- Windows 安装输入仅为 codex-elves-remote.exe，内置独立后台与固定工具；升级清理旧程序及快捷方式，保留用户数据。

## 浏览器交互

在带 CSP 和 X-Frame-Options: DENY 的本机模拟服务中运行真实浏览器，使用构建后的管理资源验证：

- 导航宽 52px；全部按钮 36×36px，距左边缘 8px。
- 管理页通过固定同源 srcdoc 加载；代理、会话管理和远程服务页面可切换。会话删除由父工作区回传确认后，模拟列表由 2 条变为 1 条。
- 自定义背景 #ddebfa 同步为管理页 rgb(221, 235, 250)。切回会话保留输入草稿、400px 阅读位置和同一个管理 iframe。
- 两个独立页面读同一版本，一端保存后，另一端旧版本保存显示冲突；未静默覆盖服务端。
- 网页设置菜单仅有设置和退出；使用 Windows 客户端标记时直接打开设置，菜单数为 0。
- 390px 窄屏下，代理设置和远程服务页面未出现横向溢出。

以上浏览器操作使用模拟数据，不代表真实供应商请求、原生会话删除或真实双设备写入已验收。真实管理授权边界另由 Rust 隔离测试覆盖。桌面锁屏，未完成与本机 Codex App 窗口的最终逐像素对照；样式参考已读取的本机应用资源及现有主题变量。
