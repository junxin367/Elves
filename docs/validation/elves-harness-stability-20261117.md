# 独立 Harness 稳定性检查

日期：2026-11-17。本记录只覆盖独立 Harness 后的运行问题，后续桌面版本调整与安装包构建单独交付。

## 发现与修复

1. **桌面会话写操作误报 401。** 本机身份保存在 `harness-desktop-device.json`，回执准入却要求该身份存在于远程设备清单。修复前回归实际返回“设备授权已撤销或过期”；现按本机或远程身份分别查询，再核对原令牌。
2. **桌面成功回执被清理。** 原清理逻辑只保留远程有效设备的回执。本机持久身份现参与回执保留，重连或后台重启后，同一请求 ID 继续复用原结果；不同内容复用同一 ID 仍返回 409。
3. **后台续发和会话命名无法恢复本机身份。** Codex、Claude 队列与自动命名统一解析操作所属身份，本机恢复不等待远程授权锁。恢复后仍逐次复核原生派发权限，本机停止、远程只读或设备撤销的限制继续生效。
4. **Claude 未读清理受远程只读开关干扰。** 确认原生历史不存在时，按本次读取的实际身份核对 `markRead` 权限。本机可以清理对应未读，只读或已撤销的远程身份不能修改未读；原历史读取错误继续返回。

上述修复不把本机身份加入远程设备列表，不修改既有持久化格式，不借用其他实例，也不恢复 Codex App 桥接或注入。

## 验证范围

- 修复前复现桌面操作返回 401，修复后核对成功回执、重复请求、内容冲突及直接回执查询。
- 验证本机无远程密钥、关闭远程会话、开启远程只读时仍可执行；本机身份恢复不等待远程授权锁。
- 验证本机重连替换令牌，旧令牌失效；重启后保留同一设备 ID 和幂等回执。
- 通过隔离 Codex 引擎、Claude 控制通道及命名生成样例验证队列自动续发、停止边界与自动命名。
- 核对本机与远程只读读取对 Claude 未读的不同结果，保留历史错误及并发新增回复保护。
