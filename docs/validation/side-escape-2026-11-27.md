# 会话标签取消 Esc 收起验收

日期：2026-11-27。

## 行为与实现

按[子会话的侧边标签规范](../product-standards/core/product-behavior.md#子会话的侧边标签)，侧边会话和子智能体的正文、输入框及外层标签栏按 `Esc` 后保持原标签和面板，不关闭、隐藏或返回主会话。

- 删除侧边页面的 Esc 收起请求及外层消息处理，不再接受旧页面发送的 `codex-elves-hide-side-panel`。
- 嵌入页在处理菜单后结束 Esc 路由，避免继续执行整页关联会话的返回逻辑；保留弹窗的原生取消行为。
- 外层会话标签栏的 Esc 不收起面板，也不冒泡误操作主会话。
- 保留标签 `×`、中键、`Delete`、面板手动开关，以及文件和变更标签的原 Esc 行为。手机整页关联会话的返回规则不变。
- 更新主规范及专题中的旧 Esc 约定，并递增资源修订。
