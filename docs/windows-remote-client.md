# Windows 远程客户端

`CodexElves-Remote-<版本>-windows-x64.exe` 是独立的 Windows x64 远程会话客户端。把 EXE 复制到另一台 Windows 电脑即可启动；需要已安装 Microsoft Edge WebView2 Runtime。客户端不需要安装 CodexElves 管理器。

Windows 安装包只安装此客户端和卸载程序，并在桌面和开始菜单的 CodexElves 分组创建“CodexElves 远程会话”程序快捷方式。安装完成页运行选项直接打开客户端；升级移除旧管理器、launcher、任务看板及旧快捷方式，保留用户数据。

## 连接

1. 启动 EXE。本机使用点击“启动本机服务”，由客户端内置的独立后台运行服务并以一次性本机证明完成配对；首次使用自动准备访问密钥，在“远程会话”页查看或更换。该操作不启动管理器、launcher 或 Codex App。
2. 连接其他电脑时填写其 HTTP/HTTPS 服务地址，并在原有登录页输入访问密钥。首次连接仍会只读探测当前用户配置的本机地址并预填，不扫描其他端口。
3. 客户端独立保留登录状态，之后启动自动打开上次成功连接地址。已保存的本机连接会恢复本机后台；用户关闭网页服务开关后保持连接页，只有明确再次点击“启动本机服务”才重新开启。远程授权过期或撤销后仍需重新配对。

服务端电脑和远程后台需要保持运行。客户端使用服务端提供的会话网页，能力和权限沿用该网页；仅支持 Android 原生桥的功能仍由 Android 提供。

本机后台与客户端使用同一 EXE 的专用运行模式。本地协议代理仅在供应商及对应代理开关开启时监听 `45221`；固定工具内嵌客户端，按 SHA-256 校验后释放到 `~/.codex-session-delete/tool-runtime/`，安装目录不另放工具程序。

## 统一工作区

左侧主导航依次为会话、代理设置、会话管理、远程会话，宽 52px、按钮 36px、左右各 8px。切换页面保留会话、草稿、侧边标签及阅读位置。代理设置合并供应商配置与本地代理状态/日志；会话管理保留浏览、筛选、单个和批量删除，移除历史修复和上下文压缩配置；远程会话保留网页、公网、密钥及设备管理。

底部设置直接打开设置界面，不显示菜单及退出项。退出程序使用托盘；网页、PWA 和 Android 的底部设置则弹出仅含设置、退出的菜单。外观由各客户端独立保存，其他配置由当前远程服务共用，配置冲突时保留输入并提示刷新合并。

本机管理使用只在真实回环有效的设备授权，可解除只读与登录锁定。普通远程设备仍受原有只读限制；管理页面复用服务 Cookie，不获得原生连接设置及本机后台启动权限。

地址无效时输入框保持可编辑。DNS、网络或证书等加载失败会返回连接页，保留本次输入并显示错误；失败地址不会替换已保存的成功地址。需要更换地址时，从托盘菜单打开“连接设置”；刷新当前页面也使用托盘菜单。

## 窗口与托盘

最顶部标题栏固定为 36 个逻辑像素，按 Windows 显示缩放比例显示。背景、文字及底部分隔线跟随会话页面的明暗模式、主题与自定义颜色，修改外观后立即同步。标题栏支持拖动、最小化、最大化和还原，窗口可缩放并记住位置与大小。再次启动时按目标显示器 DPI 恢复关闭前的逻辑大小和物理位置；同屏且完整可见时保持原值，屏幕空间不足时只作必要的缩小或平移，原位置离开所有显示器时居中。关闭按钮将窗口收进托盘；点击托盘图标或再次启动同一 EXE 可唤回原窗口。窗口不显示“连接”“窗口”菜单栏；托盘菜单提供打开、收起、最大化／还原、连接设置、刷新与退出。

任务栏角标按会话栏实际显示为未读的主会话数量显示，执行中的会话不计未读，执行结束且仍有未读标记时恢复计数。最近、置顶和项目中的重复会话去重，侧边子会话、子代理和归档会话不单独计数；读完后减少，为零时清除，超过 99 显示 `99+`。

PC 布局中“文件”“变更”在右侧标签面板打开，可以同时保留多个文件及差异，聊天继续可用。拖动面板左侧边界调宽，标签可切换和关闭；网页与 EXE 共用此界面，更新服务端网页后使用相同行为。

配置默认位于 `%LOCALAPPDATA%\com.codexelves.remote\`，其中 `settings.json` 保存成功连接地址、是否使用本机服务及窗口状态，`webview\` 保存独立登录缓存。服务共享设置仍位于 `~/.codex-session-delete/`。开发验收可用 `CODEX_ELVES_REMOTE_DATA_DIR` 隔离客户端连接与窗口数据；该变量不隔离服务端共享设置，不可据此启动测试服务并改写正式数据。

托盘退出只安全回收当前客户端拥有的本机后台；连接其他服务时退出客户端不停止服务端。安装升级会短暂关闭客户端和本机后台，卸载保留上述用户数据。旧管理器热更新脚本不用于部署统一客户端，详见[服务更新](remote-service-update.md)。

独立会话窗口和文件预览窗口的任务栏及 Alt+Tab 标题与窗口内容对应：会话窗口显示 `<会话标题> · CodexElves`，随重命名和会话切换同步；文件预览窗口显示 `<文件名> · CodexElves`（变更为 `<文件名> · 变更 · CodexElves`）。客户端监听页面标题变化，只更新该窗口自身的原生标题，页面不获得窗口控制命令；加载中或页面只返回地址时保留当前标题。主窗口及窗口内的顶栏仍显示程序标题“CodexElves 远程会话”。

独立会话窗口和文件预览窗口与主窗口一样在主界面线程创建，原生标题栏及其按钮归属该线程；打开命令只等待创建结果，不在后台线程创建 Win32 窗口，否则主线程调整窗口时会跨线程等待并导致整个客户端无响应。单实例按程序标识区分，与正在使用的客户端并行验收时，须用 `TAURI_CONFIG={"identifier":"<测试标识>"}` 构建测试版并配合独立数据目录，否则新进程只会唤醒已运行的客户端。

## 网页资源缓存

客户端内置公开网页资源包，并在 `web-resources\` 中按服务 Origin 保存校验后的完整更新及上一版。清单、文件大小和 SHA-256 均验证通过后才提交候选；相同文件优先复用现有或内置内容，只下载差异。支持 gzip 传输，编码及解压后都有限额。

已连接的服务优先从本地打开，后台检查更新。新版资源在下次刷新或重新打开页面时启用，当前会话不自动刷新；前台消息、历史等请求会让后台资源更新暂缓。服务不可达时仍可加载网页界面，会话同步和发送仍需服务在线。

此缓存由 Windows 原生层处理，普通 HTTP 也适用；API、上传和登录校验均不进入资源缓存。原服务地址与浏览器 Origin 保持不变，接管旧 Service Worker 时只停止其注册，不清除 Cookie、外观设置、草稿或 IndexedDB。

本机地址探测仅使用当前用户 `.codex-session-delete/settings.json` 的监听端口以及默认 `45222`，只连接回环地址并验证公开资源清单；不会扫描端口，也不会取用访问密钥。已保存地址和正在编辑的内容优先于探测结果。

## 构建

在仓库根目录执行：

```powershell
.\scripts\build-windows-remote.ps1
```

该入口仅构建客户端，不构建 Android，也不启动任何服务。会话原生模块无需 npm 构建；修改共享管理页面后，先执行 `npm --prefix apps/codex-elves-manager run vite:build`，让客户端内嵌最新管理资源。产物为：

- `dist/windows/CodexElves-Remote-<版本>-windows-x64.exe`
- `dist/windows/CodexElves-Remote-<版本>-windows-x64-build-info.json`，记录版本、大小及 SHA-256。

版本取根 `Cargo.toml`；默认使用本地增量 `release-fast`，正式优化构建可加 `-Profile release`。常规 `scripts/build-windows-installer.ps1` 在安装包内包含客户端，同时额外生成便携 EXE。GitHub Windows 构建和发布流程使用相同的打包范围。

客户端源码位于 `apps/codex-elves-remote/`。顶栏为 Rust/Win32 原生控件，不创建 WebView，窗口操作不授权网页。连接设置和本机后台启动命令只授权内置连接页；远程页面仅使用已登记的配色、资源缓存、未读角标、独立窗口和本机拖贴接口，并核对当前服务来源。管理 iframe 不增加原生命令权限，其他来源的链接交给默认浏览器打开。
